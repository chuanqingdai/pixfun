# 素材组合适配：先有素材，再有模板

步骤3实际查看素材后读取并应用；步骤5实例化模板时复用。这里的“支持”表示制作规范允许这种输入，不证明宿主渲染器已经实现；图片解码、多图合成、文字、音轨均须分别测试。

## 1. 按组合决定制作方式

| 可用组合 | 推荐方向与片长起点 | 必须适配的内容 |
| --- | --- | --- |
| 1张照片 | Postcard/Coastal，约6–10秒 | 单主视觉、短标题、可选注释和安全轻运动；不硬凑多场景/20秒 |
| 2–3张照片 | Contact Sheet/Postcard，约10–18秒 | 每张有完整可辨展示；图文/窗口动画形成变化，不要求视频或现场声 |
| 4–8张照片 | Contact Sheet/Split，约16–26秒 | 按主体/构图组织，必要时精华选用；拼贴只在主体仍可辨时使用 |
| 1段视频 | 按内容选模板，约8–18秒 | 只有确实发生独立阶段才拆段；静态长镜头做短片，不重复假装多机位 |
| 2–8段视频 | City/Type/Postcard等，约12–29秒 | 动作/景别互补，保护关键对白，原声与配乐有实际映射 |
| 照片 + 视频 | Contact Sheet/Split/Postcard，约12–26秒 | 照片承担空间/细节/收束，视频承担真实行动；不强制视频必须在开头 |
| 照片 + 音频，无视频 | 按纯照片设计，约10–26秒 | 音频先核对用途与许可；提供的是讲解则保留语义，不当作现场录音 |
| 无声视频 / 全部原声不可用 | 按视觉内容选择 | 原声项标记有依据的不适用；用合法音乐或用户要求的静音，不生成假现场声 |
| 横竖混合 / 方图 / 全景图 | 先确定主体安全画布，再选模板 | 单幅contain/cover、留白或双窗按内容决定，不强行裁9:16或拉伸 |
| 重复图 / 低清 / 截图 / 严重模糊 | 按可用独有内容重新计算 | 排除无价值重复；低清减少裁切与放大，截图文字不可乱裁；严重损坏明确说明 |

长度只是起点，服从用户小于30秒的要求与内容密度。3张图不必固定15秒；若都是相似风景，做8–12秒可能更好。用户只要分析时，仅输出理解与方案，不因为已找到模板而渲染。

## 2. 可替换槽位与不可替换事实

- **主视觉/高光**：照片与视频都可。优先主体可辨、构图完整，不按“有没有运动”排序。无人照片不补人物。
- **行动**：视频保留实际动作；照片只作为某个姿态/状态展示，槽位改为“画面细节”，不能描述成已观看到行动过程。
- **互补细节**：独立照片/片段优先；高分辨率局部裁切可作为同一素材的展示变化，标记同源，不算新增事件。
- **拼贴**：需要至少两幅有比较价值且可辨的画面。合影裁人、场景太杂或素材重复时换单幅；不是所有组合都启用所有效果。
- **定格**：视频可取真实停稳帧；照片本来就是静态，记录为照片，不添加“视频定格”伪事件。
- **声音**：照片没有同期声；可用用户提供且语境确认的录音或合法音乐。无对白就不生成对白字幕，不展示空字幕轨道。音乐缺失按用户要求决定静音替代或保留未完成状态。
- **地点/时间**：没有可靠证据就省略或用中性场景短句。导入时间、文件创建时间不能自动当拍摄日期；不能从照片序号推导真实行程。
- **片尾**：用现有素材自然结束；没有新素材就延续最后主视觉与短句，不回放开头伪装一个新场景。

优先级：用户限制与事实 → 完整主体/动作/对白 → 画面与文字可读 → 叙事 → 模板效果数量。缺槽位时允许缩短或减少效果，不因为模板不适合而要求用户补无必要素材。

## 3. 仅3张图片：完整15秒示范方案

前提：实际查看后确认P1/P2/P3是三张可用、有差异的旅行照片，没有音轨。可以是广景、细节、人物，也可以完全无人；按实际内容排序，不套用不存在的人物/路线。采用 `travel-contact-sheet` 的纯照片变体，rich约5次包装事件。

### 先理解与计划

1. 探测格式、尺寸、EXIF方向和色彩；HEIC/广色域须用真实解码器测试，代理不替代最终原图。
2. 查看完整图片，标出主体/合影边缘、可放字位置、清晰度和安全取景范围。按语义选择P1吸引注意、P2补充信息、P3收束，不强称真实拍摄先后。
3. 画布按主体安全决定9:16或16:9；不安全时用留白。三张都没有安全移动余量就全部静止，只让图文组件运动。
4. 文案为实际图片写2–5词短题及必要注释；不凭空使用示例地名。选曲按合法性与试听结果确定，用户不需要音乐就不建音乐轨。

### 镜头和包装时间表

| 成片时间 | 主画面 | 包装与节奏 |
| --- | --- | --- |
| 0–2.5s | P1 | 全幅主视觉 + 短片名；0.25s入场，足够稳定阅读后退场 |
| 2.5–5s | P1延续 | 标题已退出，再出现一句画面注释；保持同一镜头，不伪装第二场景 |
| 5–7.5s | P2 | 一次约0.3s留白窗口揭示；可带编辑索引，属于同一个组件组 |
| 7.5–10s | P2延续 | 窗口已停稳，出现一条细节短题；没有有价值文案就取消，画面继续 |
| 10–13s | P3 | 硬切到完整构图，无字主视觉3秒；合影不裁人，不强制推近 |
| 13–15s | P3延续 | 简短收束文字或细线，音乐自然收尾；不新增全屏空卡 |

这不是三张静图直接硬切：标题入退场、一次窗口揭示、细节注释和结尾排版构成包装；但不承诺生成不存在的相机运动。P1可在安全范围1.00→1.03轻推近；P2已有窗口动效时不再叠加明显推近；P3保持干净稳定。文字是可选信息，不能为凑5次事件强塞无意义句子。

30fps实例的主画面占用为P1 `[0,150)`、P2 `[150,300)`、P3 `[300,450)`，总450帧/15秒；照片的 `source_range` 为null，显示时长由成片帧区间决定，不伪造5秒源视频。5秒处的窗口揭示发生在P2的区间内，底层为登记的设计背景，不增加片长。10秒处硬切，无重叠额外计时。

### 轨道与效果检查

- V主画面：3个照片元素连续覆盖；按源方向/色彩正确解码。辅助背景仅在版式需要时存在，不能遮住主体。
- G图文：标题、两条可选注释、窗口遮罩/索引、收束组件有独立ID，可在后续对话中修改。
- A音乐：可选一首已授权纯音乐，源范围真实、片尾收音；无原声/对白就不创建虚假的现场声或字幕内容。
- 图片不具备源音轨，因此原声保留/对白避让检查为有理由的 `NOT_APPLICABLE`，不是失败。没有音乐且用户接受静音时音频测量同理；不能把未实现音乐误标为不适用。
- 窗口动画未验证就不得按rich完整通过：先测试，失败则说明可改静态画册版并确认；导入/规划成功不等于照片合成已成功。

生成后实际查看每张图的入场、稳定、退场和手机尺寸预览，检测黑帧/缺图/抖动/遮脸/缺字/重复填时，检查最终小于30秒。只有静帧截图不能证明动效流畅；连续审片不足要列明未验证项。

## 4. 应覆盖的组合验收用例

以下是待执行用例，不是已通过记录。每次运行记录输入、选择、实际文件、证据和状态。

| 输入与要求 | 预期可观察结果 |
| --- | --- |
| 3张不同照片，15秒，英文重包装 | 3图均清楚展示、文字有依据、图层动画实际可见、无虚构原声，留3秒干净主视觉 |
| 3张竖屏合影，要求横屏 | 完整人物优先，留白/安全contain，无拉伸或强推近裁脸 |
| 3张几乎相同风景 | 说明重复性，选较好照片缩短/轻包装，不假装3个地点 |
| 3张照片，不要字不要音乐 | 取消全部装饰文字与音乐，真实照片仍可合成，不空建轨道或擅加音效 |
| 3张照片，只有图片解码但无图文合成 | 报告效果能力缺口；不宣称重包装完成，按批准的简化方案或阻塞处理 |
| 1图+1段带对白视频 | 图片没有伪造原声；视频完整保留重要对白，音乐避让只作用可靠区间 |
| 全部低清图，要4K且少于30秒 | 区分输出尺寸与真实细节，减少放大，不承诺修复到4K画质 |
| 仅音频 / 0个可用图像视频 | 明确缺少视觉素材，保留草稿并引导导入，不生成空白旅行短片 |
