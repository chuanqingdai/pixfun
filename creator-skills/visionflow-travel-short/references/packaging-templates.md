# Travel Short · 包装模板与编排规则

这6套模板是制作配方，不是渲染器能力声明。进入 SKILL.md 步骤5时读取；按素材选择一套，实例化、测试、确认后再合成。所有示例词句只在画面支持时使用，不直接当作项目事实。

## 共同执行约定

- 模板版本均为 `1.0`；默认英文上屏。事实地名/日期来自 `facts.json`，创意短句来自 `copy.json`，示例里的人物、交通、海岸或咖啡不是必须存在的素材。
- 时间表表示最终成片时间，左闭右开；转场包含在表内，不在总时长上额外相加。秒数在实例化时按真实帧率一次量化；不是固定30fps的硬编码。
- `rich` 增加出现次数与版式变化，不增加同时显示的文字组数。至少留1.5–3秒无新增文字/明显效果的主视觉；字幕与完整动作优先。必要时主动减包装并写明理由。
- 构图按实际画布与主体安全区重新布局，不直接把9:16坐标缩放为16:9。边距、字体、阅读时长和图层冲突遵循主 Skill 第5节；文字完整可读时间不包含淡入/淡出。
- “定格”只使用真实源帧并登记有意静态区间；图形揭示不是AI生成场景。禁止伪造相机时间码、GPS、票号、胶片拍摄证明或航班信息。
- 动效用显式关键帧表示：相对组件帧、opacity、位置/裁切、scale、easing。常用 `easeOutCubic`；同一时刻最多一个主要图形运动，不能把“丝滑/电影感”留给渲染器猜测。
- 每套的替代方案都可能改变用户批准的效果。记录原因与差异，按步骤6确认；未被批准的静态版本不能冒充动态模板已完成。
- 所有模板按 [素材组合适配](material-adaptation.md) 解析槽位：照片可承担主视觉、细节、结尾，但不能冒充运动或同期声；视频可按真实独立区间填槽，不能把相同镜头重复计算成新素材。先删掉缺失槽位再重新配时，不能把整张示例时间表等比拉长。纯照片使用标题/布局/窗口动画，不要求每张都推近，也不默认使用生成式图生视频。

## A. Editorial Postcard · 动态旅行画册

`template_id: editorial-postcard` · 适合1–4段风景/慢动作或照片，主视觉清楚、负空间充足。建议12–20秒；示范18秒，rich约5次包装事件。

视觉系统：米白 `#F4F1E8`、墨绿 `#173229`、一处低饱和金；已验证的衬线标题与无衬线小注释。只在指定画册段收进边框，不全片永久缩小画面。

| 成片时间 | 画面与包装 | 实现要点 |
| --- | --- | --- |
| 0–3s | 最强真实画面上叠2–4词片名，如 `Along the Shore` | 0.3s淡入并上移短边1%，稳定阅读至少1.5s；文字不盖主体 |
| 3–6s | 动作/细节旁出现一行注释和短细线 | 线与文字同组0.2s显露；注释必须对应本镜 |
| 6–9s | 画面收进留白版式，角落出现场景小标签 | 约0.35s矩形窗口插值，保持源纵横比；标签不伪装真实邮戳 |
| 9–12s | 用画册边界擦除到互补镜头，延续一句短题 | 擦除约0.3s，填满画布后文字稳定；无需翻页3D透视 |
| 12–15s | 干净全幅高光 | 不加新文字或转场；保留可用现场声 |
| 15–18s | 最后画面与短收束；可选真实定格0.6s | 文案跨定格前后保持可读，定格不是额外加时 |

需要：文字/透明图层、矩形裁切窗口动画、图形擦除、必要的真实定格。缺擦除时可提议硬切到留白版，缺布局动画时用静态留白版；两者都须说明。只有一个有效视角时去掉互补镜头段，缩短为8–12秒，不重播凑18秒。

## B. City Notes · 城市动态笔记

`template_id: city-notes` · 适合3–6个街道、交通、店铺或人物行动区间。建议15–24秒；示范20秒，rich约6次包装事件。

视觉系统：暖白与炭黑、从素材取一种强调色；无衬线短题、细信息条和方向一致的色面。编号仅代表编辑段落，不冒充旅行日。

| 成片时间 | 画面与包装 | 实现要点 |
| --- | --- | --- |
| 0–3s | 行动主视觉 + 短题，如 `On These Streets` | 整句0.25s滑入并停稳，不逐字弹跳 |
| 3–6s | 细节镜头 + 一条具体观察 | 信息条在负空间，不挡路牌/人脸；少于7词 |
| 6–9s | 同方向色面擦除到另一景别 + 小段落标记 | 约0.25s，动作方向不支持时直接硬切 |
| 9–12s | 人物/主体动作 + 一句动作短题 | 保留动作完整，文字稳定不跟踪抖动 |
| 12–15s | 无字高光或真实现场声片段 | 音乐适当退后，禁止合成虚假的人物反应 |
| 15–17s | 空间细节 + 已确认地点/中性场景标签 | 使用一处已验证图标或细线，不堆多个徽章 |
| 17–20s | 结束镜头 + 简短回扣 | 用尾部真实动作收住，避免宣传式结束卡 |

需要：文字位置/透明度动画、局部底条、定向色面遮罩、音乐包络。没有遮罩时提议匹配硬切；没有负空间时删去对应信息条，不降低字号硬塞。对白密集时改balanced而不是让字幕与笔记竞争。

## C. Type in Motion · 大字节奏短片

`template_id: type-in-motion` · 适合2–5个动作鲜明、对白少的片段，用户希望明显的动感包装。建议12–20秒；示范15秒，rich约5次包装事件。

视觉系统：一种粗无衬线字、暖白/炭黑和一种强调色；大字是清晰的主题提示，不是跳字歌词。单词可大，但不超过安全区域，也不压关键动作。

| 成片时间 | 画面与包装 | 实现要点 |
| --- | --- | --- |
| 0–3s | 最强动作 + 1–3词题，如 `Keep Walking` | 标题0.25s由遮罩显露，稳定1.8s后退场 |
| 3–5.5s | 互补镜头 + 一个具体名词/动词 | 单组文字位置变化，不同时保留上一组 |
| 5.5–8s | 强调色色面短擦除，揭示下个画面与短题 | 0.25s单次擦除，无白闪/RGB分离；新短题有阅读停留 |
| 8–10.5s | 动作自然停稳 + 定格强调词 | 定格约0.5s，标题贯穿相邻运动帧；不制造新的动作 |
| 10.5–13s | 干净全幅高光 | 不添加动态字；不为踩点截断动作 |
| 13–15s | 收束短题与自然尾音 | 0.2s淡入，充分停留；不以长句塞满结尾 |

需要：可测量的粗字体、文字裁切遮罩、图形擦除、真实定格。关键帧/遮罩不可用时可提议静态大字硬切，但须标明视觉表现不同。低清不通过放大/锐化变成高清；强抖动与长对白不适合此模板。

## D. Split Stories · 双画面旅行拼贴

`template_id: split-stories` · 适合3–6个互补广角/细节或混合横竖片段。建议16–24秒；示范21秒，rich约6次包装事件。

视觉系统：干净矩形双画面、统一留白、细无衬线标签。最多两幅；每幅主体可辨。竖屏优先上下分区，横屏优先左右分区，但以实际安全构图为准。

| 成片时间 | 画面与包装 | 实现要点 |
| --- | --- | --- |
| 0–3s | 全幅主视觉 + 片名 | 不用小格子作为首个吸引点 |
| 3–6s | 广角与对应细节组成双画面 | 0.35s揭示第二窗，最多一个窗口有明显版式运动 |
| 6–9s | 双画面停稳 + 一条关系注释 | 只有证据表明同时发生才可暗示同步；否则是编辑对照 |
| 9–12s | 主窗口扩展回全幅 + 场景标签 | 0.35s窗口扩展，不拉伸原图，不裁掉同伴 |
| 12–15s | 第二组真实对照 + 短题 | 无第二组素材就删此段，不复制镜头伪装新视角 |
| 15–18s | 全幅无字高光 | 两路原声只选有价值一路或明确混音，不能自动双倍叠声 |
| 18–21s | 收束画面 + 小标题 | 回到单主焦点，不在结束时堆更多面板 |

需要：多视频合成、独立视口/裁切、窗口关键帧、明确音轨映射。缺多画面能力时提议按顺序单幅展示，不能声称“拼贴已完成”。画面分辨率低或只有一个视角时换模板，不拿同源模糊背景充第二视角。

## E. Travel Contact Sheet · 旅行影像手账

`template_id: travel-contact-sheet` · 适合2–6张真实照片，可选搭配1–3段视频；纯照片无需补视频。通常12–25秒，3张照片优先12–18秒；以下24秒示例仅用于内容足够的组合，rich约7次包装事件。仅3张照片使用素材适配文档中的15秒方案，不强套这张24秒表。

视觉系统：米白底、深灰衬线片名、统一窄留白与小号索引。索引表示选片顺序；不做假拍立得日期、假胶片参数或伪机票。

| 成片时间 | 画面与包装 | 实现要点 |
| --- | --- | --- |
| 0–3s | 最佳照片/视频全幅 + 片名 | 图片仅在分辨率允许时轻推近 |
| 3–6s | 第二画面以手账窗口显露 + 编辑索引 | 0.3s裁切揭示；索引与窗口算同一次包装事件 |
| 6–9s | 两张互补照片短暂双图 + 一条注释 | 不用三宫格/九宫格把普通照片缩到不可辨 |
| 9–12s | 双图中的一张扩展 + 具体场景小题 | 0.4s矩形窗口扩展，禁止非等比拉伸 |
| 12–15s | 真实视频或下一照片 + 已确认地点小标签 | 用原声给画面生命力；纯照片项目不伪造现场声 |
| 15–18s | 第二组细节 + 细线注释 | 不足素材时删段并缩短；不将一个裁切说成新事件 |
| 18–21s | 无字主视觉 | 放回完整构图，合影不裁人 |
| 21–24s | 简洁封底式版式 + 收束短句 | 沿用真实画面与主题，最后1秒不再引入新信息 |

需要：静态图片/视频混合时间线、轻推近、矩形窗口、多图合成和字体。缺多图能力时可提议单图手账；照片不足不下载无关景色充当用户经历。只剩单张可用照片时优先Postcard并缩短时长。

## F. Coastal Light · 海岸光影短笺

`template_id: coastal-light` · 适合1–4段水面、岸边、船或安静自然场景。建议12–22秒；示范18秒，rich约5次包装事件。

视觉系统：暖白、沙色与素材中的水色；宽留白、稳定文字、柔和窗口显露。包装频率较高但运动慢，不能把晴天滤成虚假的黄金时刻。

| 成片时间 | 画面与包装 | 实现要点 |
| --- | --- | --- |
| 0–3s | 真实主视觉 + 简短片名，如 `By the Water` | 0.3s透明度渐入，保持水面/人脸细节 |
| 3–6s | 近景/动作 + 一句具体注释 | 稳定文字配局部渐变，不全片压灰 |
| 6–9s | 半幅留白揭示细节 + 场景标签 | 约0.4s窗口显露；地平线不倾斜、人物不被切断 |
| 9–12s | 短叠化回全幅 + 一条短题 | 约0.3s，有足够源手柄；人脸重影则改硬切 |
| 12–15s | 干净景色或完整人物动作 | 保留真实水声/脚步；不要在这里叠新词 |
| 15–18s | 结尾留白与可选短句 | 原声和乐句完整收尾，不用长黑场凑时长 |

需要：文字/局部渐变、矩形窗口、叠化与安全取景。缺窗口动画时提议纯全幅配短题；快速车流、强手持运动或密集对白通常改用其他模板/更低强度。

## 模板实例化与验收

`packaging.json` 保存设计意图，最终效果必须编译到 `timeline.json`。每个组件至少记录下列内容，不能只保存模板名：

| 字段 | 必须包含的含义 |
| --- | --- |
| `id / type / track / z_order` | 稳定组件ID、文字/窗口/遮罩/定格类型、实际图层和顺序 |
| `t / asset_refs / source_ranges` | 成片整数帧区间、真实素材引用、源视频/音频范围；纯图形无源时间 |
| `copy_id / fact_ids` | 实际文案版本与事实来源；纯装饰没有事实就用null |
| `layout / keyframes` | 与实际画布对应的矩形/安全区、相对帧上的数值动画、插值与缓动 |
| `transition_refs / handles` | 两端镜头、重叠范围、源手柄；效果结束后的确定状态 |
| `capability / evidence / fallback` | 所需功能、真实测试文件/帧证据、用户批准的替代及差异 |

先用最复杂组件做内部测试，再给用户展示简短计划；不要让用户先选了不可实现的效果才揭露限制。最终审片除主Skill第8节外，还核对：所有已批准组件实际可见、每条文字有阅读时间、rich不是杂乱叠加、拼贴返回全幅无跳裁、定格/叠化登记正确、干净主视觉存在、音效有授权且不是冒充现场声。

修改时保留组件ID：减少包装优先删次级注释/第二次版式变化，减轻动效优先缩短位移并保留阅读时间；“更有设计感”不能自动理解为增加随机转场。用户选中一个片段提修改时，只调整关联组件与必要衔接，保留上一版用于比较。
