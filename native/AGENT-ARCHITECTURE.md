# Pixfun 本地优先 Agent

## 产品链路

需求＋用户选定素材 → 意图识别 → 必要澄清 → 按需素材理解／缓存 → 对应成果。

不是强制六步向导。`analyze` 输出画面分析，`search` 输出可跳转的原片片段，`subtitles` 输出转写和 SRT，`plan` 输出故事时间线而不渲染，`create/modify` 输出待确认编排，确认后本地生成预览。结果与对话保存在 Project；用户可继续修改需求或进入同页时间线编辑。

- 只有目标不明确、没有素材、没有可修改的时间线或能力不支持时才追问。
- 确认分两种：上传前逐任务确认云端数据范围；生成前确认故事编排。不反复确认可撤销的本地分析。
- 单列项目对话页：按创建时间展示用户需求、助手回复、必要追问、真实运行步骤及结果；合成视频直接在对应消息内播放／导出。历史轮次保留结果，时间线与详细日志默认折叠，底部输入框固定。浏览历史时不强制滚到底部，可点 Latest 返回最新消息。
- Work log 记录真实工具阶段与已处理数量，镜头 reason 解释选择依据；不展示或伪造模型私有思维链，也不生成假百分比。运行时可停止并修改，失败可重试。
- 不用虚假百分比或倒计时；首次模型载入可能较慢，完成的素材理解会缓存，后续请求复用。
- 预览编辑支持原片入出点、顺序、删除和锁定。保存使用版本检查，旧预览不会冒充新版本。原素材不修改。
- 云端失败不静默切换本地；本地失败也不自动上传。错误、缺失能力和中断均可见。

## 分层与接口边界

```
SwiftUI Home / Agent / Media / Project
                 │ 原生会话鉴权，本机回环 HTTP
desktop_service → AgentEngine（持久状态、权限、调度、时间线校验）
                 ├─ ModelGateway（稳定的能力接口）
                 │   ├─ 离线 JSON-lines worker → 现有 VisionFlow 本地实现
                 │   └─ 显式配置／授权的云端 JSON adapter
                 ├─ Library（本地文件引用、元数据、分镜、现有字幕）
                 └─ FFmpeg / AVKit（抽帧、预览、校验、播放／导出）
```

UI 不直接依赖模型名称、进程或供应商。后续替换本地模型只改 Gateway/worker，不改 Agent 状态机；新能力按同样合同增加方法、可用状态、来源及失败结果。现有 VisionFlow 项目没有被修改，也没有自动调用它的云端兜底。

| 本地接口 | 复用实现 | 当前调用场景 |
| --- | --- | --- |
| `ask(prompt, cancel, images?, max_tokens)` | `vf_engine.Engine`，MLX Qwen3-VL-4B | 意图、抽样画面理解、故事编排、修改、检索结果核验 |
| `transcribe(source, cancel)` | `mlx_whisper`，本地 Whisper large-v3-turbo-q4 | 现有字幕缺失时的人声转写；字幕任务不做视觉分析 |
| `rank(images, query, cancel)` | `vf_agent.search`，SigLIP2 | 语义检索相似度排序，再用画面证据核验，不把相似度当概率 |
| `inspect(images, cancel)` | `photo_metrics` + Apple Vision OCR | 清晰度、亮度、过曝／欠曝、倾斜、画面文字；OCR 不可用会明确标识 |
| `motion(source, cancel)` | `vf_motion` 光流函数 + 可移植 FFmpeg 解码 | 运镜序列、抖动、稳定区间、突变，供编排参考 |

光流／画质是本地算法而非语言模型；保留真实来源。人物身份分组、人物筛选与 `/people` 接口已移除；不能按人物身份跨素材检索。

Gateway 的 `capabilities()` 返回安装检查与本次会话实际执行状态，区别 `not-tested`、`verified`、`failed`。未执行不宣称验证成功。模型权重、Python runtime 和源码位置可由 `PIXFUN_MODEL_PYTHON`、`PIXFUN_VF_ROOT`、`PIXFUN_LOCAL_VLM`、`PIXFUN_LOCAL_ASR`、`PIXFUN_LOCAL_RETRIEVAL` 指定。始终以离线模式加载，不自动下载。

## 对外本机 API

全部 Agent 路由需要每次启动生成的服务 token 和 native token，不暴露到网站。

| 方法／路由 | 合同 |
| --- | --- |
| GET `/api/desktop/agent/capabilities` | 能力安装／执行状态、供应商和模型配置；不返回密钥 |
| GET `/api/desktop/agent/runs` | 最近 100 次任务、阶段、成果、来源、时间线和版本 |
| POST `/api/desktop/agent/start` | `requestId`（幂等）、`prompt`、`mediaIds`、`mode`、可选项目 `id` 和 creator skill |
| POST `/api/desktop/agent/action` | `id`＋`stop/retry/approve/timeline`；编辑另传 `version` 与 `timeline` |
| POST `/api/desktop/agent/configure` | HTTPS endpoint、text/vision model、key；执行期间禁止更换配置 |

运行状态：`queued → running → clarify / review / completed / failed`；云端先进入 `consent`。停止进入 `cancelled`，重启后未完成任务进入 `interrupted`，均需显式重试。单队列限制重模型同时占用内存；停止会结束模型 worker 进程组。云端 HTTP 已发出的请求不能撤回，取消后不提交结果，最迟受 120 秒网络超时约束。

## 证据与缓存

SQLite 保存 Project、AgentRun、素材理解缓存。原片保留原路径；只保存引用和抽帧、转写、临时预览等衍生物。

- 视觉缓存键包含源路径、尺寸、修改时间、处理模式、模型和分析版本；不能把旧模型／旧文件结果直接混用。
- 视频编辑分析每 6 秒窗口抽 3 帧，作为切点审核与可编辑分镜的证据；通用观察接口默认 15 秒。保留 mediaId、起止时间、画面摘要、图像指标和运镜估计。不是逐帧完整理解，不保证捕获短暂事件。
- 字幕独立缓存并保留时间码；疑似重复幻觉会计数提示，不能把删减后字幕称作无损完整转写。
- 时间线只能引用本次选定视频，源入出点必须有效，数值有限，锁定片段不可改变，最长 10 分钟、最多 80 镜头。
- 预览校验音视频流、分辨率与总时长；采用原声／静音轨、保留原画面比例加边，不宣称已完成配乐或智能重构图。
- 默认 LGPL FFmpeg 包使用 MPEG-4 Part 2/AAC MP4 预览；有 libx264 的运行环境可用 H.264。原片格式不会变化。

## 云端边界

`local` 全本地；`hybrid` 本地素材理解、云端文本规划；`cloud` 云端规划与抽样视觉理解。ASR、检索、画质和运镜仍走本地。Hybrid 的文字证据可能含转写，Cloud 还可能含抽样帧，均在确认中说明。

原片与原音频不上传；云端配置保存在 macOS Keychain，服务端仅内存持有。只允许支持的 HTTPS 供应商，不跟随重定向；更换目的地／模型后旧审批不适用。没有供应商、模型权限和 API Key 时不能声称云端真实联调成功。

## 验收与尚未完成的能力

### 导入的 Travel Vlog v5.4

`travel_skill.py` 通过固定 skill ID 读取随服务打包的原始 `creator-skills/visionflow-travel-director/SKILL.md`，校验版本并记录 SHA-256 和适配器版本；不读取客户端提供的任意路径，不把输入框的摘要当完整规范。当前提取并应用原文中的叙事、节奏、覆盖、时长和事实优先级规则，**不是完整九步后期生产实现**。

路由接收技能默认（16:9、片长随内容），但“只分析／检索／字幕”不会被技能升级成生成任务。规划接收真实分镜证据、源元数据、明确标识的用户位置/设备信息以及原始叙事条款；用户明确要求优先。无明确总时长时向规划模型传 null，以实际时间线长度回填，不默认凑 30 秒。后续项目对话继承所选技能。

默认检查每个选定文件是否在正文中出现，片头闪现与重复源区间不计足够正文覆盖；这只是结构检查，不证明全事件/对白语义完整。漏项先进行一次模型修正，仍不满足则集中询问全覆盖或精选，未确认不可渲染。用户保存的手动时间线视为明确选段并更新覆盖报告。报告包含版本、原规范哈希、每个文件的源区间和露出时长、未接通能力，统一标为 NEEDS_REVIEW，关键事件完整性 UNVERIFIED。

当前技能接通的是视频故事方案和原声粗剪。原规范要求的授权音乐下载/听审、混音避让、照片动效、竖屏模糊背景、章节卡、地点标签、全片视听验收和完整交付包尚未实现，不能宣称完整 Skill 已验收。界面详情与对话中的技能报告明确列出边界。原文件保持不变。

### 验证范围

2026-09-30 输入链路走查：Home 和项目草稿独立；输入超过 5,000 字符、导入进行中、其他项目占用、模型未配置时在提交前提示。仅缺素材的追问在补充素材后允许直接 Continue。后续请求携带前一轮问题、意图和状态，编排也接收这些上下文；修改默认保留画幅和总时长，明确的新时长优先。音频分析强制走转写；混入音频/图片的编排任务先澄清，不默默忽略附件。模型设置 Cancel 不提交模式，保存失败保留弹窗及错误。

`tests/agent.test.py` 是使用明确 fixture 模型的状态／安全合同测试，不是模型效果证明。
`scripts/verify-agent-local.py` 使用真实 Qwen、SigLIP2、Whisper 和 FFmpeg，隔离临时数据库，检查澄清、只分析、篝火检索、故事方案、粗剪、渲染、修改、字幕及人声转写。结果输出 `build-native/agent-real-cases.json`，包含每项状态、来源、时间线与耗时。

当前是可验证的本地粗剪闭环，不是所有视频生产能力都已完成：自动配乐混音、生成配音、字幕烧录、转场、精细音频语义剪切、全面成片审美评估和发布尚未接入；任务应明确提示限制，不能假装执行。长片视觉理解上限 60 分钟／素材，规划上限 160 个窗口；超限明确提示缩小范围，不静默截断。

这台开发机已有所需大模型 runtime 与缓存；新 Mac 的模型安装、体积／内存检查、许可清单与升级管理仍需要独立交付，不等于安装当前 app 就自动具备全部大模型。下一阶段优先将上述能力封装成可安装的本地运行时，沿用同一 Gateway 合同。
